# 从零安装与运行（本地 / CI）

面向**没有 GPU** 的笔记本或 CI：只安装轻量依赖，跑通单元测试与烟雾测试，确认代码本身正确。
真正跑索引、SFT 和 GRPO 见 `在线平台部署.md`。

## 1. 环境

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements/00-base.txt
pip install -r requirements/04-dev.txt
pip install -e . --no-deps
```

## 2. 跑测试

```bash
python -m pytest -q          # 当前轻量环境：40 passed, 4 skipped
python scripts/smoke_test.py  # 输出 {"status": "ok", ...}
```

烟雾测试覆盖：RRF 融合顺序、多级/二值奖励、EM/F1/MRR/NDCG/Recall、官方 test 严格筛选、对比报告生成。
它不需要 GPU、torch、faiss、bm25s，安装失败也能验证核心逻辑。

## 3. 只做数据处理

不需要 GPU 也能验证数据流程（`nq` 用官方 test、`hotpotqa` 用官方 dev）：

```bash
python scripts/download_data.py --data-dir /tmp/search_r1 --qa-only
python scripts/prepare_data.py --data-dir /tmp/search_r1
cat /tmp/search_r1/processed/data_stats.json
```

重点看四个字段：`eval_sources`（保留）、`dropped_sources`（剔除及原因）、
`difficulty`（easy/medium/hard 分布）、`augment_stats.deficits`（哪些分层需要补样本）。
不设 `LLM_API_KEY` 时查询扩展会自动跳过并记录 `missing_api_key`，其余流程照常完成。

## 4. 上 GPU 平台

```bash
pip install -r requirements/01-torch-cu121.txt
pip install -r requirements/02-retrieval.txt
pip install -r requirements/03-verl-training.txt     # 仅训练机
python scripts/check_env.py --data-dir /data/search_r1
```

然后按 `在线平台部署.md` 的流水线阶段执行。
