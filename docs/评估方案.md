# 评估方案

## 1. 数据集

只用 `nq` 和 `hotpotqa`（向 Search-R1 看齐），评测必须带标准答案：

| 数据集 | 评测 split | 理由 |
| --- | --- | --- |
| nq | `test` | 官方 test 公开答案 |
| hotpotqa | `dev` | 官方 test 不公开答案，Search-R1 同样在 dev 上评测 |

split 可通过 `--eval-splits nq=test hotpotqa=dev` 覆盖。任何数据集被剔除时，原因写入
`processed/data_stats.json` 的 `dropped_sources`：

| 剔除原因 | 含义 |
| --- | --- |
| `split_missing(no_<split>)` | 指定 split 的文件不存在 |
| `answers_missing(answer_rate=x)` | split 存在但标准答案缺失率过高 |
| `too_few_rows(n)` | 条数少于 `--min-rows` |

## 2. 六组对比

| 变体 | 模型 | 检索 | 回答的问题 |
| --- | --- | --- | --- |
| `base` | Qwen2.5-3B | 双路 | 基线 |
| `sft` | base + 2k 高分轨迹 SFT | 双路 | SFT 冷启动比基座好多少 |
| `grpo_binary` | SFT + GRPO（0/1 奖励） | 双路 | 0/1 奖励的 GRPO 比基座好多少 |
| `grpo_multi` | SFT + GRPO（多级奖励） | 双路 | 多级奖励的 GRPO 比基座好多少 |
| `compare` | 参考模型（qwen3.5-4b） | 双路 | 与参考基模的差距 |
| `grpo_multi_single` | 同 `grpo_multi` | **单路** | 双路 vs 单路召回 |

六个变体共用同一份 test、同一套指标、同一份 prompt，唯一变量是模型权重或检索路数。

## 3. 指标定义

**答案质量**

- `EM`：归一化后与任一 gold 完全相同
- `F1`：token 级 F1，对多个 gold 取最大
- `Judge`：LLM-as-a-judge，1–5 分归一化到 0–1，需要 `--judge`

**检索质量**（用模型自己发出的 `<search>` 查询，对同一 RRF 服务重放）

- 相关性：检索到的段落标题出现在 `supporting_facts` 中（二值相关）
- 候选池：一次轨迹内所有搜索的候选按最佳名次合并去重
- `Recall@K` / `MRR@K` / `NDCG@K`：K 默认 10

没有 `supporting_facts` 的数据集（NQ）不参与检索指标，该列为空。

**行为质量**

- `Evidence`：检索内容是否覆盖答案实体与支持文档
- `Format`：标签合规性
- `Efficiency`：惩罚多余轮次、重复查询、无效动作
- `Searches` / `Latency(ms)` / `Tokens`

## 4. 报告

- `artifacts/report/comparison_report.md`：整体表 + 分数据集表，含相对 `base` 的 `ΔEM`、`ΔF1`、`ΔMRR@10`、`ΔNDCG@10`
- `artifacts/report/comparison.json`：结构化结果
- `artifacts/report/comparison_overall.csv`
- `artifacts/eval/<variant>/eval_traces.jsonl`：逐条轨迹，供人工抽查

## 5. 消融解读

- **SFT 的作用**：`sft - base`，看 EM/F1 与 Format（格式合规率通常提升最明显）
- **奖励设计的作用**：`grpo_multi - grpo_binary`，多级奖励应改善证据率与效率，而 EM 不一定大涨
- **检索路数的作用**：`grpo_multi - grpo_multi_single`，双路在 Recall@10 / MRR@10 上应占优，进而带动答案指标
- **与参考模型的差距**：`compare - base`，判断小模型 + RL 是否追平更大的通用基模

## 6. 实验记录

每组实验填一份 `docs/experiment_log.md`，记录 commit、GPU 型号数量、基座模型与 revision、教师模型、
语料与索引 manifest、保留/剔除的数据集、难度分层分布、增强生成条数、SFT 奖励阈值、GRPO 步数与
FIFO 混入比例、六个变体的全部指标、失败案例与结论。结论中的每个数字都应能由对应产物的 commit 回放。
