# 在线平台部署（AutoDL / 4×4090）

## 0. 两种部署形态

**A. 单机（AutoDL 4×4090）**

检索服务在本机以 **CPU** 模式启动，不占训练显存：

```bash
python scripts/run_all.py --data-dir /data/search_r1 --n-gpus 4
```

流水线在索引建好后启动一个检索实例：`8000/retrieve` 为双路 RRF，`8000/retrieve?ways=dense` 为仅稠密消融，不会复制第二份索引。

**B. 训练机 + 独立检索机**

| 机器 | GPU | 职责 | 常驻服务 |
| --- | --- | --- | --- |
| 训练机 | 4 × RTX 4090 | SFT、GRPO、评测推理 | 无 |
| 检索机 | GPU 或 CPU，按索引规模配置内存 | IVF-PQ、BM25、RRF | `serve_retriever.py :8000` |

```bash
# 检索机：先下载语料并建索引
python scripts/download_data.py --data-dir /data/search_r1 --corpus --sources nq hotpotqa
python scripts/build_indices.py --data-dir /data/search_r1 --dense --bm25
python scripts/serve_retriever.py --data-dir /data/search_r1 --port 8000 --ways both

# 训练机：准备 QA 和模型后从 sft-data 阶段继续
python scripts/download_data.py --data-dir /data/search_r1 --qa-only --models \
  --sources nq hotpotqa --compare-model Qwen/Qwen3.5-4B
python scripts/prepare_data.py --data-dir /data/search_r1 --augment
python scripts/run_all.py --data-dir /data/search_r1 --n-gpus 4 --from-stage sft-data \
  --retriever-url http://<检索机IP>:8000/retrieve --no-start-retriever
```

## 1. 环境

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements/00-base.txt
pip install -r requirements/01-torch-cu121.txt
pip install -r requirements/02-retrieval.txt      # faiss-gpu + bm25s + transformers

```

veRL 建议按平台推荐版本从源码安装（`pip install --no-deps -e <verl-src>`），并把版本记进实验日志。

## 2. 流水线阶段

`scripts/run_all.py` 按下列顺序执行，可用 `--from-stage/--to-stage` 断点续跑：

| 阶段 | 内容 | 产物 |
| --- | --- | --- |
| `download` | QA 数据集 + 21M 语料 + 模型权重 | `<data-dir>/{qa,corpus,models}` |
| `indices` | e5 编码 + IVF-PQ 训练 + BM25 构建 | `indices/{e5_ivfpq.faiss,bm25,doc_offsets.npy}` |
| `prepare` | 质量过滤 + 难度分层 + 查询扩展 | `processed/{eval,train_pool}.jsonl`、`data_stats.json` |
| `sft-data` | 教师采样 2k 高分轨迹 + 建 FIFO | `processed/sft_train.jsonl`、`fifo.jsonl` |
| `eval-baseline` | 基座 + 双路 | `artifacts/eval/base/` |
| `sft-train` | 4 卡 SFT | `models/sft` |
| `eval-sft` | SFT + 双路 | `artifacts/eval/sft/` |
| `grpo-binary` | GRPO + 0/1 奖励（含 FIFO 混入） | `models/grpo_binary` |
| `eval-grpo-binary` | 同上评测 | `artifacts/eval/grpo_binary/` |
| `grpo-multi` | GRPO + 多级奖励（含 FIFO 混入） | `models/grpo_multi` |
| `eval-grpo-multi` | 同上评测 | `artifacts/eval/grpo_multi/` |
| `eval-compare` | qwen3.5-4b 基模 | `artifacts/eval/compare/` |
| `eval-single-way` | 多级 GRPO + 单路召回 | `artifacts/eval/grpo_multi_single/` |

结束后汇总到 `artifacts/report/comparison_report.md`。

## 3. 关键参数

```bash
python scripts/run_all.py \
  --data-dir /data/search_r1 \
  --base-model Qwen/Qwen2.5-3B \
  --compare-model Qwen/Qwen3.5-4B \
  --teacher-model deepseek-4.1-flash \
  --augment-model deepseek-4.1-flash \
  --sft-target 2000 \
  --fifo-mix-ratio 0.10 \
  --n-gpus 4 \
  --judge                       # 打开 LLM-as-a-judge（额外 API 消耗）
```

先用 `--max-samples 200 --grpo-steps 50` 短跑验证全链路，再放开。

## 4. 单独运行各阶段

```bash
python scripts/download_data.py --data-dir /data/search_r1 --qa-only --corpus --models
python scripts/build_indices.py --data-dir /data/search_r1 --dense --bm25
python scripts/prepare_data.py --data-dir /data/search_r1 --augment
python scripts/generate_sft_data.py --data-dir /data/search_r1 --target 2000
python scripts/update_fifo.py --data-dir /data/search_r1 --from-sft
torchrun --nproc_per_node=4 scripts/train_sft.py --data-dir /data/search_r1 --model Qwen/Qwen2.5-3B
bash scripts/train_grpo.sh /data/search_r1              # REWARD_MODE=multi|binary
python scripts/compare_models.py --data-dir /data/search_r1
```

## 5. 时间与资源参考（单张 4090）

| 步骤 | 参考耗时 | 说明 |
| --- | --- | --- |
| 编码 21M 段落 + 建 IVF-PQ | 依 GPU、语料格式和存储速度而定 | 先在小语料验证索引构建 |
| BM25 构建 | 依内存和磁盘速度而定 | 当前构建器一次加载语料正文，建议预留 ≥64 GB 内存并监控峰值 |
| SFT 采样与训练 | 依教师 API 与 GPU 而定 | 保存实际调用量、步数和耗时 |
| GRPO 训练 | 依步数而定 | 可先用 50 步验证流程 |
| 单变体评测 | 依样本数和推理速度而定 | 保存逐条轨迹与汇总 |

## 6. 排障

| 现象 | 处理 |
| --- | --- |
| `bm25s` 未安装 | `pip install bm25s`，或 `--bm25-backend rank_bm25`（仅小语料） |
| FAISS GPU 训练显存不足 | 减小 `--train-size`，或加 `--cpu` |
| 查询扩展没生成 | 未设 `LLM_API_KEY`，脚本会记录 `missing_api_key` 并跳过（不影响后续阶段） |
| 分层数量仍不均衡 | 提高 `--max-new-rows`，或把 `--balance-target` 改为 `max` |
| hotpotqa 被剔除 | 检查是否只有 `test.jsonl`（官方 test 无答案），应使用 `dev.jsonl` |
| `compare` 变体加载失败 | 检查模型名、访问权限及 GPU 内存，用 `--compare-model` 指定实际模型 |
| 评测全 0 分 | 看 `eval_traces.jsonl` 的 `search_count`，确认 agent 真的发起了搜索 |
| veRL 报未知配置项 | 加 `--upstream-verl` 切换采样数配置键 |
